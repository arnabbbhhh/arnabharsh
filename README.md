## 📌 Featured Projects

### 🔷 [FPGA FFT using Booth Multiplier](https://github.com/arnabharsh/fpga-fft-booth-multiplier)
> **IEEE Published** — Compact and energy-efficient 8-point FFT on FPGA using a custom Booth multiplier-based MAC unit. Designed in VHDL on Xilinx Vivado with full testbench and timing analysis.

### 🚗 [Smart Parking System — STM32 + FreeRTOS](https://github.com/arnabharsh/smart-parking-freertos)
> Real-time 4-slot parking system using STM32F446RE and FreeRTOS. Multi-task architecture with IR sensors, PWM servo gates, queue/mutex inter-task communication, and UART logging.

### 💡 [Visible Light Communication on FPGA](https://github.com/arnabharsh/vlc-fpga)
> B.Tech project — VLC system using two ZYBO FPGA boards. OOK modulation over LED, LDR reception, and real-time image display over VGA. Full PL-based design in VHDL.

### 🤖 [Line Follower Robot — TM4C123GH6PM](https://github.com/arnabharsh/line-follower-tm4c123)
> Autonomous line-following robot using ARM Cortex-M4. Dual-speed PWM strategy (60% forward, 95% turns) with IR sensors and L298N motor driver.
